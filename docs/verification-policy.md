# Verification policy

Verification must be appropriate to the claim and as independent as practical from the process that generated the claim.

Possible strategies include:
- Recompute expected values using a separate code path.
- Compare with trusted reference outputs.
- Use analytical derivations or formal proofs where appropriate.
- Apply property-based tests and search for counterexamples.
- Repeat stochastic experiments and report variability.
- Use held-out data when required by the evaluation design.

A verifier should document its method, scope, assumptions, and failure cases. A passing verifier is not automatically evidence of scientific novelty or universal truth.
